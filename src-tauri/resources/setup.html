Google 健康数据

从 Google 同步步数、心率、睡眠等数据。
需要 OAuth 2.0 凭据，按下方步骤 5 分钟即可完成。

如何获取 Client ID 与 Secret？
  1. 打开 Google Cloud Console 并登录你的 Google 账号
  2. 顶部选择或新建一个项目，然后搜索并启用 Fitness API
  3. 进入「API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID」
  4. 应用类型选择 桌面应用，点击「创建」
  5. 复制页面上的 Client ID 与 Client Secret，填入下方输入框

如何获取 API Key？
  1. 打开 DeepSeek 开放平台，注册并登录
  2. 进入「API Keys」→「创建 API Key」，复制生成的 sk-… 密钥
  3. Base URL 填 https://api.deepseek.com，模型填服务商提供的模型名（如 deepseek-v4-flash）
  4. 也可以选择「自定义」，手动填写任意 OpenAI 兼容服务的 Base URL 与 Key
  5. 注意：调用需账户有余额，欠费时提示不生成（自动回落到本地规则提示）
