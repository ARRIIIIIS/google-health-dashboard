👋 欢迎使用健康仪表盘

这是一个把你手机/手表的健康数据（步数、睡眠、心率、血氧等）显示在电脑上的小工具。
数据全部存在你本地，不上传任何云端。

第一次使用需要花约 5 分钟连接你的 Google 健康数据。跟着下面几步点就行，不用懂技术。

第 1 步 · 创建 Google 项目

先在 Google 后台新建一个项目（用来申请数据读取权限）。

操作
  • 打开 Google Cloud 控制台并新建项目
  • 记住项目名称即可，无需其他设置
https://console.cloud.google.com/
🔗 打开控制台

第 2 步 · 启用健康数据接口

在刚才的项目里，把"Google Health 数据接口"打开。

操作
  • 进入「API 库」搜索并启用 Health API
https://console.cloud.google.com/apis/library/health.googleapis.com
🔗 打开 API 库

第 3 步 · 创建登录凭据

创建一个"OAuth 客户端 ID"，并把下面的回调地址原样填进去。

① 创建凭据

控制台 → APIs 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID → 应用类型选「桌面应用」。

② 复制回调地址，粘贴到「已获授权的重定向 URI」
http://127.0.0.1:8911/oauth/callback
③ 创建后，把客户端 ID 和密钥填到下面

第 4 步 · 用 Google 账号授权

点击下方按钮，会弹出 Google 登录页。登录并允许读取健康数据后，会自动回到这里。

  • 已完成 Google 授权
